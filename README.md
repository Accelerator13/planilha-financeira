# Planilha Financeira

Controle de receitas e despesas feito com HTML, CSS e JavaScript puro, em um único arquivo.

## Recursos

- Cadastro, edição e exclusão de lançamentos
- Totais de receitas, despesas e saldo
- Filtro por mês e por categoria
- Gráfico de despesas por categoria e comparativo dos últimos 6 meses
- Exportação para CSV (abre direto no Excel)
- Dados salvos no `localStorage` do navegador
- Tema claro e escuro automático

## Como usar

Abra o arquivo `index.html` no navegador. Não precisa instalar nada.

## Observação

Os dados ficam salvos apenas no navegador em que foram digitados. Use a exportação em CSV para guardar uma cópia.
